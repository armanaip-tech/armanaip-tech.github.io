# Порядок осуществления закупок — обучающий семинар 2026

Одностраничный информационный веб-портал для обучающего семинара по закупкам группы компаний АО «Самрук-Қазына». Готовится и читается лектором Айып А., ТОО «Самрук-Қазына Контракт», ИСЭЗ.

## О проекте

Портал — учебно-информационный ресурс для демонстрации на очном семинаре (проектор, большой экран). Контент сверен с:

- консолидированной редакцией Порядка осуществления закупок, версия **2.17** (с изменениями по состоянию на 30.04.2026);
- решением Совета директоров АО «Самрук-Қазына» №259 от 26.08.2025;
- решением Совета директоров АО «Самрук-Қазына» №269 от 18.02.2026;
- решением Совета директоров АО «Самрук-Қазына» №274 от 30.04.2026.

Действующая консолидированная редакция имеет приоритет перед сравнительными таблицами и проектными материалами.

## Возможности

- три этапа закупочного цикла, планирование, 4 действующих способа закупки, реестры и приоритеты 2026 года;
- тендер целиком: сроки, тендерная документация (Приложение №5), техническая спецификация, условные скидки, антидемпинг, обеспечение, основания отклонения, несостоявшийся тендер;
- ЗЦП, закупка из одного источника (все основания статьи 59), электронный магазин;
- договор: заключение, изменение, перечень ненадёжных поставщиков;
- раздел «Изменения 2026 года», разделённый на три волны решений (№259, №269, №274) с форматом «было → стало → практика → нормативное основание» по каждому пункту;
- sticky-навигация с активным разделом, индикатор прогресса страницы, кнопка «наверх», полноэкранный режим, режим показа с увеличенным текстом.

## Технологии

Один файл `index.html`: HTML5 + CSS3 + vanilla JavaScript, без сборки, без сервера, без интернета. Открывается двойным кликом в любом современном браузере (оптимизировано под Chrome и Edge).

## Локальный запуск

Просто откройте `index.html` двойным кликом — либо через локальный сервер:

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.
