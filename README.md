# Закупки АО «Самрук-Қазына»: порядок, процессы и практика

Интерактивный учебный портал по работе с [zakup.sk.kz](https://zakup.sk.kz) — планирование закупок, реестры и перечни, выбор поставщика, управление договорами, заключительные положения и актуальные изменения Порядка осуществления закупок АО «Самрук-Қазына».

Подготовлено ТОО «Самрук-Қазына Контракт», Департамент сопровождения ИСЭЗ. Лектор: Айып А.

## О проекте

Портал — учебно-информационный ресурс, а не замена официального веб-портала закупок или официальной редакции нормативного документа. Контент основан на:

- консолидированной редакции Порядка осуществления закупок с изменениями по состоянию на 30 апреля 2026 года;
- решении Совета директоров АО «Самрук-Қазына» №259 от 26.08.2025;
- решении Совета директоров АО «Самрук-Қазына» №274 от 30.04.2026.

Проектные предложения по изменению Порядка, ещё не утверждённые Советом директоров, промаркированы на портале как «Проект изменения» и не представлены как действующие нормы.

## Возможности

- официальный текст 61 статьи Порядка (статьи 11–74) с точной нумерацией пунктов и подпунктов;
- 5 учебных разделов: планирование закупок, реестры и перечни, выбор поставщика, управление договорами, заключительные положения;
- раздел «Изменения Порядка» с фильтрами и сравнением «Было / Стало»;
- интерактивный тест из 10 вопросов с подсказками и объяснениями;
- словарь из 70+ терминов (статья 2 Порядка);
- полнотекстовый поиск, режим презентации для лекций, локальное сохранение прогресса обучения.

## Технологии

Ванильные HTML / CSS / JavaScript (без сборки и зависимостей) — контент вынесен в JSON-файлы (`assets/data/`), отдельно от разметки и логики (`assets/js/main.js`).

## Локальный запуск

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.
